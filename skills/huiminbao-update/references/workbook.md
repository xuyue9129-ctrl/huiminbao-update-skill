# 既有工作簿维护与验证

## 不可变基准

先看`latest_progress.json`，再检验实际SHA、表头、数据行和工作表名。OOXML文件名如`sheet22.xml`不等于22张表，要通过`workbook.xml`及关系表解析。现有公式/批注/外部链接/名称/隐藏表是用户资产，不可通过重建空白工作簿丢弃。

`workflow.py inspect`给出当前哈希、各表尺寸、公式和缓存错误概况。不要因旧进度写着“完成”就跳过未读正文，也不要因最新修改时间自动选取临时重算副本。

## 补丁工具的明确边界

`workflow.py apply`只修改既有单元格，不插行、不生成来源表、不调整未知结构。它用标准库XML替换对应worksheet，保留其余zip部件内容，保留目标cell未更改的属性和子节点。XML命名空间前缀/序列化可能变化，验证应区分字节差异与语义差异。

补丁协议（示意，SHA和expect必须来自本次inspect，不可照抄）：

```json
{
  "base_sha256": "本次基准的64位sha256",
  "changes": [
    {
      "sheet": "Summary",
      "cell": "Q10",
      "expect": {"type": "n", "value": "100", "formula": null, "style": "2"},
      "op": "set",
      "value": 120,
      "reason": "当年官方价格已变化",
      "evidence_refs": ["decisions/demo.json#Q"]
    }
  ]
}
```

inspect的`--cells Summary!Q10 Summary!BY10`返回可直接用于expect的payload。类型和value是OOXML原始值（日期通常为数值序列）。`op`支持：

- set：数值/文本/布尔；日期用`{"date":"2028-01-01"}`并配现有日期style_id；
- clear：清内容，不自动表示withdraw正确，必须有依据；
- formula：`formula`不带`=`，清旧缓存，可用`cache`和`cache_type`提供经Excel验证的值；无缓存须重算；
- style：仅样式；`style_id`必须是已有cellXfs索引，不能猜“红字=某固定ID”。

每项都要`reason`、`evidence_refs`。可附`style_id`改变已存在样式索引。新增红字/黄底组合需另建样式变体并独立校验，不能覆盖共享样式而改变其他格。apply拒绝重复坐标、缺原值校验、未知op、未知工作表、范围外坐标及输入/输出覆盖；不验证研究结论真实性。

```powershell
python -X utf8 workflow.py inspect --workbook $base --cells 'Summary!Q10'
python -X utf8 workflow.py apply --workbook $base --plan $plan --output $candidate --log $changeLog
python -X utf8 workflow.py verify --workbook $candidate
```

## 新年度插行：不可省略的迁移

1. 按地区+稳定产品ID+产品名称+当前年度重新定位，不沿用上次插入后的旧坐标。
2. 确认新增年度证据，计算每个插入点及累计偏移，生成“旧行→新行”映射。
3. 从相邻正确版本复制格式、行高和日期格式，清空不能继承的业务参数，只填本年有依据值。
4. 公式相对引用用公式转换器，跨表/绝对/范围引用按语义分别处理；简单正则全局替换数字会误改年份/产品号/金额。
5. 复核命名范围、表、合并、打印范围、筛选、条件格式、数据验证、超链接、批注/VML、图表/透视及外部关系。工具无法保真时停止，不能静默丢弃。
6. 重算K地区分组序号，核验保单年系列；来源总览H列行号、I列跳转及详情块同步调整，逐条测试可达。
7. 与未修改基准按映射逐格比对：旧值/公式/格式应原样迁移，只有计划列允许改变；验证新行数与新增产品数，不以“文件能打开”代替正确性。

历史批次脚本可作为本工作区实现参考，但其固定行号/文件名/源路径不能打包成通用执行入口，也不得未经阅读直接运行。

## Excel重算与错误对比

```powershell
# 两个命令分别在新进程/独立Excel实例运行，目标临时路径必须不存在
python -X utf8 recalculate.py --input $base --copy $recalcBase --report $baseReport
python -X utf8 recalculate.py --input $candidate --copy $recalcOut --report $outReport
```

脚本DispatchEx创建独立Excel实例，关闭宏、禁外链更新，不触及用户现有Excel实例。先拒绝带数据连接的工作簿，避免打开时自动外联。Excel只保存copy；最终源文件哈希前后必须相同。

报告含各表公式的表达式/缓存和真实错误值。以两份重算报告的错误坐标和值比较，新增#REF!等必须解决；缺参保率的CE#N/A只能在核验公式和空销量后列为预期，不能泛化豁免整列。若插行，先应用旧新行映射再比对。

COM `.Value`会把错误变成负整数，如-2146826246，而不是产品数据。始终从已保存临时副本用`data_only=True`读取错误字符串；写回OOXML时`t=e`。空字符串不等于不存在公式。回嵌缓存是工作簿内容修改，需写日志并重验最终文件。
